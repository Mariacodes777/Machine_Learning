# Machine_Learning

Machine Learning Repository

This repository contains a collection of Python and R Jupyter notebooks showcasing various machine learning techniques, exploratory analysis workflows, and model‑building examples.

Featured Notebooks

Penguins Seaborn Dataset  
A clean, approachable dataset used to explore preprocessing, visualization, and supervised learning. Includes Logistic Regression and Random Forest models to predict penguin species based on physical characteristics.

Titanic Survival Prediction  
A classic introductory dataset used to demonstrate feature engineering, exploratory analysis, and classification modeling. Although widely used, it remains a helpful and familiar example for teaching foundational ML concepts.

Heart Disease Dataset  
A less commonly explored dataset focusing on predicting heart disease risk using logistic regression and other supervised learning methods. This notebook provides a more medically oriented example of classification modeling.
